## 摄影风格基准:古偶权谋·赵小丁式(整部片统一,所有镜遵循)

> 作用:这是全片的影像风格锚点。不要只写"赵小丁风格",必须把它落实到每镜的色温、光质、明暗比、景别、机位、构图和质感锚定里。

### 风格总原则

- 调色基调:低饱和青灰冷调为底,每镜色温优先写 `冷青灰` 或 `冷蓝`;暖黄默认只作局部点缀(烛火/灯笼/夕照),避免全片暖黄、粉白、棚拍写真感。
- 暖场例外:仅 `闪回回忆` / 婚庆喜宴 / 童年亲情 / 疗愈团圆可用低饱和 `暖黄` 作主调;仍需保留侧逆光或柔逆光、明暗 `6:4` 或 `7:3`,禁止正面平光和过曝甜腻。权谋/审讯/密谋/黑化/夺权场景不得使用暖黄主调。
- 光质取向:侧逆光/侧光勾边为主,允许大光比硬朗阴影,常用明暗 `7:3` 或 `8:2`;暧昧亲密可降到 `6:4`,但不能无阴影平光。
- 构图取向:权力场景优先对称构图、中轴线、中心权力位、门框/柱廊/屏风切割;情感场景保留空气感和留白。
- 机位取向:运镜稳、慢、克制,优先 `static` / `lock-off` / `slow dolly in 0.3x` / `crane up/down` / `arc shot right 15°`;少用 `handheld`,只给追逐紧张或刺杀混乱。
- 景别取向:每节第一镜优先用全景/中全景交代人景关系;权谋对峙用中近景/近景压迫;关键情绪只给一次特写或大特写。
- 质感锚定:统一写电影级、浅景深或中等景深、服化道材质清晰、轻微胶片颗粒;禁止塑料感、美颜棚拍感、过曝仙气。

### 场景到摄影参数映射

| 场景/情绪 | 优先机位与构图 | 优先光质 | 明暗比 | 质感关键词 |
|---|---|---|---|---|
| 朝堂/审讯/权力压迫 | 中轴线、低机位、对称构图、人物被柱廊/门框切割 | 侧光分光 / 冷色顶光眼窝阴影 | 8:2 | 低饱和青灰、金黑暗红、压迫秩序 |
| 暗中密谋 | 侧脸、背影、隔帘/屏风遮挡、一明一暗 | 侧光分光 / 硬侧光 | 7:3 或 8:2 | 烛火暖点、窗外冷月光、半明半暗 |
| 男女主初见 | 先大全景/全景定场,再长焦中近景/特写,轻微仰视或平视 | 侧逆光 / 柔逆光 | 6:4 或 7:3 | 发丝轮廓光、低饱和背景、宿命感 |
| 暧昧亲密 | 双人同框、一前一后、隔纱/同灯下、手部特写 | 柔逆光 / 柔光漫射 | 6:4 | 暖烛光、浅景深、克制亲近 |
| 刺杀/夜战 | 先全景交代空间,关键招式低机位逆光,动作中景/全身景 | 硬光高对比 / 强逆光剪影 | 8:2 | 冷蓝月光、暖色火点、刀锋轮廓 |
| 黑化/夺权 | 人物从暗处走向中轴线,低机位,背后大空间 | 冷色顶光眼窝阴影 / 侧光分光 | 8:2 | 冷白逆光、剪影、权力吞噬 |
| 虐恋/诀别 | 远景拉开距离,门/雨/雪/帘/桥隔开,背影优先 | 强逆光剪影 / 柔光漫射 | 7:3 | 冷天光、低饱和、留白、孤独 |

### 与 §2-② 光影规则的优先级

1. §1.1 的分镜类型词决定本场光质大方向。
2. 本"摄影风格基准"决定整片调性,负责收紧色调、明暗、构图、机位和质感。
3. 两者冲突时,以本基准为准:古偶权谋不允许正面平光、无阴影、过甜高 key、随意手持、花哨运镜。
4. 每镜的 `[时间码 · 色温 · 光质 · 明暗比]` 必须体现本基准,不要只在节头写一次。

**③ 站位** — 用画面几何

只能用三种区域描述及其组合:**画面左 1/3**、**画面中**、**画面右 2/3**。**禁止**抽象描述。

**④ 视线** — 强制必填

**⑤ 动作描述** — 写动作链,不写动作步骤

- ❌ 错(动作步骤):`抬手,然后转头,然后开口`
- ✅ 对(动作链):`抬手转头开口`

**⑥ 台词 / 内心OS / 画外音** — 三种发声方式,**严格区分**(语义不同 AI 处理不同)

**关键区分**(术语硬规则):

| 字段 | 谁说 | 嘴动 | 声纹要求 | 字段名 |
|---|---|---|---|---|
| **台词** | 画面里角色 | 嘴动同步 | 用该角色声纹 | `台词:角色名:「...」` |
| **内心OS** | 画面里角色 | 嘴不动 | 用该角色声纹(本人心声) | `内心OS:角色名:「...」` |
| **画外音** | 画面外的人 | 无嘴(画外) | 可任意,旁白/不在场角色 | `画外音:角色名:「...」` 或 `画外音:旁白:「...」` |

**铁律**:三种字段**必须以 `角色名:` 开头**,不允许只写引号内容,否则 AI 视频会随机挑角色配音 → 错张嘴。

**判定方式**(剧本原文标记):

- 普通对话(嘴动)→ `台词:`
- `(内心OS)` / `(心想)` / `(暗道)` / `(心声)` → `内心OS:`(本人嘴不动,自己听见自己的心声)
- `(画外音)` / `(旁白)` / `(VO)` / 不在场角色叙述 → `画外音:`

❌ 错(无说话人 / 用错字段):

```
画外音(voiceover):「叶拂柳!她要对凌家二小姐动手?」  ← 没说话人 + 字段名错
```

✅ 对(说话人 + 字段名匹配实际语义):

```
台词:容景渊:「孤为太子,她们不敢妄议。」                    ← 画面里嘴动
内心OS:凌瑶华:「叶拂柳!她要对凌家二小姐动手?」              ← 画面里凌瑶华嘴不动,本人心声
画外音:旁白:「这一刻,凌府的命运悄然改写。」                  ← 画外旁白
画外音:容景琛(回忆):「妹妹,以后哥哥护你。」                   ← 画外回忆某角色的话
```

**说话人必须来自本节"人物"字段白名单**(画外音的"旁白"是例外,可不在白名单)。

- 有台词必写原文 + 说话人:`台词:角色名:「中文原文」`
- **禁止**用"(略)"、"见对话"、"口型与台词对应"等占位
- 无台词时**直接省略此行**,不写"台词:无"

### 3.3.0 输出纪律(最高优先,违反 = 整节作废重写)

§3.3.1~§3.3.8 是你的【内部心算流程,不是输出格式】。定语速、算时长 D、算段数、算容量、判断超速,全部在脑子里完成,【绝不写进输出】。

输出里每个镜号必须是【一次成型的最终结果】:
- 时间码连续递增,不重排、不重叠、不回退(后镜起点 = 前镜终点);
- 【台词字数/容量】必须【已经满足 X ≤ Y】才能出现;某段超容量,在落笔前就先拆好,输出里【不出现】超速的镜。

【绝对禁止】出现下列任何一种(出现 = 整节作废):
- "应拆/重算/修正/超速/需再拆/调整镜长/改X字每秒为Y字每秒"等任何过程或元叙述文字;
- 被否决的镜号(先写一个错的,再写一个对的);
- 同一句台词的"草稿镜 + 修正镜"并存,或两个镜时间码相同/重叠。

你可以在心里反复试算,但纸面上只准留【最终那一版】。

### 3.3.1 台词处理总原则(关键 — 绝不删字,只给足时长)

核心思想:台词是原文,一个字都不能删、不能改、不能用"(略)"省略。
镜长装不下台词时,不是砍字,而是【切到下一个镜号继续念】——靠切镜换景别/机位制造视觉密度,同时给足时长让 AI 有演绎空间(表情、语气、情感)。

为什么要给足时长:语速过快时,AI 的算力全耗在"按时念完字"上,出来的脸是平的、语气是干的、没有情感。台词时长一定要按语速算准,宁可多切一个镜,也不让演员赶着念。

一句话原则:**3.5s 用来决定是否拆、拆几段;实际镜长用来校验每镜是否超速。**

### 3.3.2 第一步:按情绪定语速(三档定值,不取区间)

读本镜台词情绪,从下表选 1 档语速(单值):

| 语速档 | 字/秒 | 适用情绪 |
|---|---|---|
| 慢速 | 4.5 | 哭腔 / 虚弱 / 压抑 / 哽咽 / 暧昧停顿 / 沉思拖长 |
| 常速 | 6   | 平静说明 / 诚恳解释 / 普通对话(默认) |
| 快速 | 7.5 | 争执 / 惊慌 / 质问 / 急促 / 愤怒 |

情绪不明显时默认【常速 6 字/秒】。

### 3.3.3 第二步:算台词字数 + 总时长

字数统计口径:
- 只数引号「」内的正文汉字 + 标点(标点代表停顿,计入,不是废字符)
- 字段名(`台词:`)、角色名(`容景渊:`)、引号本身,都【不计】
- 绝不允许为凑数删字

```
总时长 D = ceil(字数 ÷ 语速 × 2) ÷ 2     # 向上取整到 0.5 秒
```

### 3.3.4 第三步:判断拆不拆、拆几段(用 3.5s 这把尺)

```
D ≤ 3.5s → 单镜承载,本镜镜长 = D,不用拆
D > 3.5s → 必须拆:
   段数         = ceil(D ÷ 3.5)
   每段目标字数 = 总字数 ÷ 段数      # 仅切点参考,非硬值
   单镜最大容量 = 语速 × 3.5         # 任何一镜字数都不得超过此值
```

例(纯数字示意):53 字 · 常速 → D = ceil(53÷6×2)÷2 = 9.0s → 段数 = ceil(9.0÷3.5) = 3 段。

⚠️ 3.5s 只用来"定段数 / 算最大容量",不是每镜都做满 3.5s。每镜最终镜长按【该镜实际字数】回算(见 §3.3.6),可能是 3.0s,甚至 2.5s。

⚠️ 单节仍受 §0.2 红线约束(单节 ≤ 15 秒)。一条台词切出的连续镜头应落在【同一节】内(跨节 = 两段独立视频会断音频);若本节装不下,按 §4 把剧情拆成新节,不要把同一句台词劈到两个节。

### 3.3.5 第四步:在哪里切(切点规则)

1. 优先在【标点处】切(逗号、句号、问号、感叹号、顿号、分号),让每段是完整语义单位。
2. 每段字数尽量靠近"每段目标字数",但【绝不超过单镜最大容量(语速×3.5)】;超了就把切点往前挪到上一个标点。
3. 前段太短装不满 → 可把后面到下一个标点的内容吸过来,合成一段。
4. 单段正文汉字 < 6 字 → 默认并入相邻段,避免"半句话一个镜"的碎镜。
   例外:爆点 / 强反转 / 情绪落点短句可独立成一镜给冲击力。例「我重生了。」「你竟然是她。」
5. 整句无标点(长句无停顿)→ 先按【称呼 / 转折 / 因果 / 动作节点】补语义停顿再切;实在切不动才按目标字数硬切。硬切【不删字、不改写原意】。

### 3.3.6 第五步:每镜回算镜长 + 标注 + 超速校验

```
本镜镜长 = ceil(本段字数 ÷ 语速 × 2) ÷ 2
本镜容量 = 本镜镜长 × 语速              # 按该镜【实际镜长】算,不拿 3.5s 兜底
```

每个含台词 / 内心OS / 画外音的镜,在发声行下方加中文标注(废弃旧的 `[X/Y]` 写法):

```
台词:容景渊:「中文原文」
【语速】6字/秒
【台词字数/容量】18/18
```

- 【台词字数】= 本段引号内字数(含标点)
- 【容量】= 本镜镜长 × 语速,向下取整
- 铁律:台词字数 ≤ 容量,必须成立。若超 = 本镜超速 → 回 §3.3.4 多拆一段重排,严禁交付超速镜,严禁删字。

### 3.3.7 跨镜连续台词 & 内心OS / 画外音

【跨镜连续念】一句台词被拆到多个连续镜号时,这几镜是同一句话不停顿地念下去,必须靠切换【景别 / 机位 / 反应对象 / 手部或道具细节】制造视觉变化,不允许几个镜全是同一景别同一机位硬撑长对白(那等于一个枯燥长定点镜)。

【内心OS / 画外音】走【完全相同】的语速、时长、切镜、容量规则。区别只在发声方式:
- 台词:嘴动,需要口型承载;
- 内心OS / 画外音:嘴不动,但仍占满音频时长,照样按语速算字数、算容量、该切就切。
OS / 画外音【不是】"塞长句不切镜"的逃生口,一样不能超速。
(动作描述配无声化词:唇抿 / 喉滚 / 睫颤 / 出神 / 侧脸,严禁写"开口/张嘴/说道"。)

### 3.3.8 完整算例(真实例句,字数已核准)

台词原文:「我知道这些年你一直都在恨我,可当年那场吞没一切的大火,你要的那个真相,今天我都可以告诉你。」

```
步骤1 情绪=诚恳解释 → 常速 6 字/秒
步骤2 字数 = 45(引号内含标点);总时长 D = ceil(45÷6×2)÷2 = 7.5s
步骤3 7.5 > 3.5 → 段数 = ceil(7.5÷3.5) = 3 段;目标≈15 字;单镜最大容量 = 6×3.5 = 21 字
步骤4 原句 4 个标点段(14 / 13 / 8 / 10),按"目标15、不超21、短段并入"归成 3 段:
       ① 「我知道这些年你一直都在恨我,」        14 字
       ② 「可当年那场吞没一切的大火,」          13 字
       ③ 「你要的那个真相,今天我都可以告诉你。」  18 字(后两个短段并入)
步骤5 每镜回算镜长 + 校验:
       ① 14字 → ceil(14÷6×2)÷2 = 2.5s,容量 2.5×6=15 ≥14 ✓
       ② 13字 → 2.5s,容量 15 ≥13 ✓
       ③ 18字 → ceil(18÷6×2)÷2 = 3.0s,容量 3.0×6=18 ≥18 ✓
       3 镜合计 8.0s,3 个不同景别/机位连续念完,一字未删 ✓
```

**⑦ 微表情·好莱坞放大** — 戏剧张力关键

即梦默认表情是"电视剧表演级"(动作小、不确定),必须命名"好莱坞放大"才能撬出戏剧张力。

写法:**眼/眉/嘴/下颌** 任选 2-3 个具体五官细节,用 ` · ` 分隔。

示例:

- `眼眶泛红 · 下颌紧绷 · 嘴角微微下压`
- `眉峰倒竖 · 太阳穴青筋微凸 · 下颌咬紧`

**⑧ 质感锚定** — 每镜必写,不能省

写 3 段:**画质等级 + 质感词 + 景深视觉**

- 画质等级:`2K 超高清` / `4K 电影级` / `IMAX 级`
- 质感词:`电影质感` / `胶片颗粒` / `冷峻数字感` / `暖光软调`
- 景深视觉:`极浅景深虚化背景` / `浅景深虚化背景` / `中等景深` / `大景深前后景清晰`

⚠️ **禁止**写 f1.4 / f2.8 / f5.6 这种 f 值数字 — LLM 训练语料里这些数字的画面感约等于 0。

**⑨ 视觉钩子** — 接下镜的理由

写法:`抬手动作引出近景` / `泪珠掉落引出怒意` / `光线渐暗引出转场` / `质问声切入对方反应`

## §3 状态继承

### 3.1 5 段标签格式(后端依赖,不能简化)

```
姿态[具体姿势] · 伤势[无伤/伤势描述] · 持有道具[道具名(状态) 或 无] · 情绪[情绪词] · 朝向关系[面向谁/目光方向]
```

- `姿态`:不可只写"站立",必须具体(如"站立,单手护婉兮"/"坐太师椅,身形僵直")
- `持有道具`:带状态(如"紫檀戒尺(沾血)"),无则写"无"
- `朝向关系`:本节内相对关系(如"面向容景琛,目光凌厉")

### 3.2 节尾结构(后端 parse 依赖,**两块都不能省**)

```
📏 本小节总时长:XX 秒

🔗 本节结尾状态:

  角色1 = 姿态[..] · 伤势[..] · 持有道具[..] · 情绪[..] · 朝向关系[..]

  角色2 = ...

  (本节所有在场角色,5 段标签齐全,供下一节继承)
```

⚠️ 每节 📏 / 🔗 **各只能出现一次**,出现两次视为输出错误。

### 3.3 节尾补充层(连贯性自检)

```
🎬 不变元素:本节跨镜不动的元素(光线方向 / 服装 / 关键道具 / 镜头基调)

🎬 渐进变化:本节跨镜递进的情绪链 / 动作链
```

示例:

```
🎬 不变元素:冷青灰侧光方向固定;容景琛护婉兮的姿态保持;凌瑶华坐位不动

🎬 渐进变化:容景琛怒意勃发 → 凝固;凌瑶华错愕 → 沉静观察
```

这两块用于检查情绪曲线连贯性,也辅助后端验证状态链。

### 3.4 同名禁令(硬规则)

- 同一个实体在整个剧本里**必须用同一个名字**
- **禁止** name normalize:把上节 `少年容景琛` 简写成 `容景琛`,或反之
- "容景琛" 和 "少年容景琛" 是**不同实体**,不继承状态

跨节继承规则:

- 本节"人物"字段里**完全同名**的角色 → 继承上节 🔗 状态
- 名字不同 → **重新构思起始状态**(标注"首次出场"或"刚进殿尚未开口"),**不能**抄少年版改个名

## §4 拆节判断(强制两步法,违反 = 输出作废)

⚠️ **硬规则**:你必须**同时**完成下面两步,然后取最大值。**不能只做第一步**。

违反下限 = 输出作废,必须重新拆节。

### 4.1 第一步:查"字数 × 类型词"区间表

| 字数 | 对峙/独白/暧昧 | 动作/追逐 | 群戏/大场面 |
|---|---|---|---|
| ≤ 300 | 1 节 | 1-2 节 | 1 节 |
| 301-800 | 2 节 | 2-3 节 | 2 节 |
| 801-1500 | 2-3 节 | 3-4 节 | 3 节 |
| 1501-2500 | 3-5 节 | 4-6 节 | 4-5 节 |
| 2501-3500 | **5-7 节** | **6-8 节** | **5-7 节** |
| 3500+ | ≥ 7 节 | ≥ 8 节 | ≥ 7 节 |

### 4.2 第二步:必算信号数(不准跳过)

逐项数下面这些"剧情切换信号":

| 信号类型 | 计 1 个的判定 |
|---|---|
| 对白人物切换 | A 说话 → B 说话(同一人连说不重复计) |
| 情绪反转 | 怒 → 悲、冷 → 热、喜 → 怒 |
| 动作冲突 | 打耳光、跌倒、摔物、推搡、扯扇 |
| 心理 OS | 内心独白、画外音回忆 |
| 镜头空间转移 | A 位移到 B、推近/拉远 |
| 揭露/反转 | 真相暴露、闪回、意图反转、身份反转 |

### 4.3 强制公式(两步取最大值)

```
最终节数 = max( §4.1 区间下限,  ceil(信号数 / 2) )
```

并且必须满足 `最终节数 ≤ §4.1 区间上限 + 2`(防过碎)。

### 4.4 计算示例(必须按此口径)

- **3000 字 · 对峙冲突型 · 数出 11 个信号**
  → max( 5 [区间下限], ceil(11/2)=6 ) = **6 节** ✓
- **3000 字 · 独白抒情型 · 数出 4 个信号**
  → max( 5 [区间下限], ceil(4/2)=2 ) = **5 节**(下限保底) ✓
- **1860 字 · 对峙型 · 数出 4 个信号**
  → max( 3 [下限], ceil(4/2)=2 ) = **3 节** ✓
- **3000 字 · 任何类型 · 输出 4 节** → ❌ **违反下限,必须返工重拆**

### 4.5 三条死线

1. **绝对底线**:节数 < §4.1 区间下限 = 错误,**必须重新拆**(2501-3500 字至少 5 节)
2. **天花板**:节数 > §4.1 上限 + 2 = 太碎,损害剧情连贯性
3. **不要把统计写进交付**:你心算这些数字,但**绝对不要**在输出里写"原文 X 字 → 推荐 Y 节 → 实际 Z 节"

## §5 镜头语言规范

### 5.1 机位多样化(硬规则)

- 本模板先遵循"摄影风格基准":权力场景优先对称/中轴线/低机位威压;爱情与暧昧用长焦、中近景、侧逆光;密谋用遮挡/侧脸/半明半暗;不为多样化牺牲风格统一。
- 同一节至少 **2 种垂直角度**(不能全平视;扁平 = AI 感 = 暴露穿帮)
- 情绪 → 机位映射:
  - 质问 / 威严 / 怒意 → **仰视 / 低角度**
  - 脆弱 / 哭泣 / 屈服 → **俯视 / 高角度**
  - 亲密 / 对峙凝视 → **平视正面 / 侧 3/4 角**
  - 定场 / 大场面 → **中全景 + 平视/微俯** 或 **鸟瞰**
- 对立反应镜对称:A 仰拍 → B 俯拍(不要都平视)

### 5.2 景别衔接

景别等级:`大全景 > 全景 > 中全景 > 中景 > 中近景 > 近景 > 特写 > 大特写`

- 相邻镜头若拍**同一对象/同方向**:景别跳跃 **≥ 2 级**,或机位偏转 **> 30°**
- 禁止连续多镜同景别同角度

### 5.3 节奏曲线(每节 4 拍模型,按类型词调整权重)

| 节奏拍 | 对峙冲突 | 动作打斗 | 独白抒情 |
|---|---|---|---|
| 镜 1 铺垫 | 全/中全景 · 平视/微俯 · 中轴定场(3-4s;权力场可低机位威压) | 中景 · 入场动势(1-1.5s) | 全景 · 慢推(3-4s) |
| 镜 2 发展 | 近景 · 角度切换(2-3s) | 近景 · 动作冲突(1-1.5s) | 中景 · 情绪累积(3-4s) |
| 镜 3 高潮 | **特写 · 仰/俯强化**(2-3s,**台词多在此镜**) | 大特写 · 动作终结(0.8-1.2s) | 特写 · 内心爆发(2.5-3s) |
| 镜 4 收束 | 中近景 · 平视/留白(2-3s) | 中景 · 后果暴露(1.5-2s) | 中景 · 余韵(3-4s) |

### 5.4 转场词

| 转场 | 用法 |
|---|---|
| `cut` | 默认硬切,节奏紧凑 |
| `dissolve 0.5s` | 情绪延续,柔和过渡 |
| `match cut` | 相同形状/动作衔接,高级感 |
| `smash cut` | 剧情突变/惊吓/对比强烈 |
| `fade to black` | 时间跳跃/章节收束 |
| `whip pan` | 快速视角切换,紧凑节奏 |

### 5.5 快剪子镜(动作打斗专用)

爆发节点用一个 shot 写 3-4 个子镜,description 里明确列:

```
子镜①[父镜开始-中点1] 动作描述

子镜②[中点1-中点2] 动作描述

子镜③[中点2-父镜结束] 动作描述
```

时间分配:

- 爆发类:每子镜 0.5-0.8s
- 环境扫描类:每子镜 0.8-1.2s
- 子镜时长之和 = 父镜总时长

## 🎙️ 三种发声方式 — 区分声纹,但全部服从 §3.3 切镜规则

| 字段 | 谁说 | 嘴动 | 触发 |
|---|---|---|---|
| `台词:` | 画面里角色 | ✓ 嘴动 | 普通对话 |
| `内心OS:` | 画面里角色,本人心声 | ✗ 嘴不动 | 剧本含 `(内心OS)/(心想)/(暗道)/(心声)` |
| `画外音:` | 画面外的人(旁白/不在场角色/回忆) | ✗ 画面无此人 | 剧本含 `(画外音)/(旁白)/(VO)` 或不在场角色叙述 |

**铁律**:三字段都必须 `字段名:角色名:「内容」`,禁止只写引号内容,否则 AI 会随机挑角色配音。

**内心OS ≠ 画外音**:
- 内心OS 是画面里这个角色的心声(本人嘴不动但听到自己心声),AI 用【该角色声纹】。
- 画外音是画面外某个声音(旁白/不在场角色/回忆),AI 可用任意 voice。

**配合规则**:`内心OS:` / `画外音:` 的动作描述必须配无声化词(唇抿/喉滚/睫颤/出神/侧脸),严禁写"开口/张嘴/说道"。

### 字数与时长:三种发声方式一视同仁(关键 — 没有谁能靠加长镜头塞长句)

三种发声方式【都必须遵守 §3.3 长句切镜规则】,任何一种都不能用"加长镜头"承载长句。

【角色对白】嘴动,需要口型承载。按情绪语速算时长,超 3.5 秒必须拆镜。
【内心OS】嘴不动,但仍占音频时长。**不得因为是 OS 就塞长句**。按同一语速规则算,超 3.5 秒必须拆镜。
【旁白/画外音】嘴不动,但仍占音频时长。按同一语速规则算,超 3.5 秒必须拆镜。

所有发声方式都必须标注(容量 = 本镜实际镜长 × 语速,见 §3.3.6):

```
【语速】X字/秒
【台词字数/容量】X/Y
```

- 若 X > Y,该镜无效,**必须继续拆镜**。
- 不得通过"延长本镜""调整镜长""容量不足但保留"等方式硬塞,不得删字。

**只输出最终分镜结果。** 不得输出"调整镜长至…""为满足容量…""此处拆分原因…"等任何过程说明(违反 = 输出不合格)。

### 反例 → 正例(内心OS 长句,务必照正例做)

❌ 错(想加长单镜硬塞,还把过程写进交付):

```
镜号3:【近景·仰视侧3/4角·slow dolly in 0.3x】[00:07-00:11]   ← 4.0s,1 个镜
内心OS:谢明渊:「看来这位凌二小姐颇通御人有术,并非色厉内荏之人。」
【语速】6字/秒
【台词字数/容量】24/24   (调整镜长至 00:07-00:11.5=4.5s 容量27)   ← 既没真拆,又把"调整镜长"写进交付
```

为什么错:整句 24 字 ÷ 6 = D = ceil(24÷6×2)÷2 = 4.0s > 3.5s,本该【拆镜】,却想靠延长一个镜硬塞;OS 不是逃生口。

✅ 对(D > 3.5 → 拆 2 镜,换景别连续念,一字未删):

```
