**③ 站位** — 用画面几何

只能用三种区域描述及其组合:**画面左 1/3**、**画面中**、**画面右 2/3**。**禁止**抽象描述。

**④ 视线** — 强制必填

格式:`角色 → 凝视/俯看/瞥向/避开 → 角色/物件/画外`

⚠️ **不写视线 AI 默认呆呆正视前方,出来像监控录像。这是即梦/Sora 通病,必须显式标。**

**⑤ 动作描述** — 分两个层级:跨镜拆关键动作,单镜内写动作链

**(a) 单镜内 = 动作链**(连贯成句,不写机械步骤):
- ❌ 错(动作步骤流水账):`她抬手,然后转头,然后开口`
- ✅ 对(动作链):`她抬手转头,压低声音开口`

**(b) 跨镜 = 关键大动作拆"起→过→收",分配到多个镜号**(便于分镜 + AI 稳定生成):
- "起身开门"不能一句带过,拆成:手撑桌沿起身 → 迈步走向门口 → 手握门把 → 转动门把推门(分到连续镜号)。
- ⚠️ **只拆"关键动作",普通表情/视线/小幅动作不强拆**(否则啰嗦)。关键动作指:走位 / 起身坐下 / 开关门 / 拿放递抢道具 / 靠近后退 / 推开拦住跪下倒下 / 改变人物位置·关系·道具状态的动作。

### 2.1.5 动作创作规则(写动作描述时遵守)

1. **具体可演**:关键动作落到具体身体动作,别用笼统词一笔带过(✗"起身开门" → ✓ 拆成撑桌起身/迈步/握把/推门)。
2. **贴人设·场景**:动作符合人物身份、当前场景;禁脱离人设/场景(高冷战神不"蹦跳",办公室不"打斗")。
3. **AI 适配(关键,防画面崩坏)**:即梦/SD2 对复杂、快速、多人交叉动作不稳。普通剧情镜优先 **慢动作 / 单人主动作 / 清晰起止 / 少肢体交叉 / 少多人同时运动**;禁"三人同时打斗、快速翻滚、高空跳跃"这类。
4. **动作传情绪**:用动作表达情绪,别只写"她很生气"——✓ 攥紧袖口 / 指尖停在杯沿 / 下颌绷紧 / 低头避开视线 / 后退半步 / 手指微颤;情绪重的动作给特写镜。
5. **前后连贯**:相邻镜动作逻辑连贯、有合理过渡,禁突兀跳变(✗"上一秒低头,下一秒突然抬手"无过渡)。

**⑥ 台词 / 内心OS / 画外音** — 三种发声方式,**严格区分**(语义不同 AI 处理不同)

**关键区分**(术语硬规则):

| 字段 | 谁说 | 嘴动 | 声纹要求 | 字段名 |

|---|---|---|---|---|

| **台词** | 画面里角色 | 嘴动同步 | 用该角色声纹 | `台词:角色名:「...」` |

| **内心OS** | 画面里角色 | 嘴不动 | 用该角色声纹(本人心声) | `内心OS:角色名:「...」` |

| **画外音** | 画面外的人 | 无嘴(画外) | 可任意,旁白/不在场角色 | `画外音:角色名:「...」` 或 `画外音:旁白:「...」` |

**铁律**:三种字段**必须以 `角色名:` 开头**,不允许只写引号内容,否则 AI 视频会随机挑角色配音 → 错张嘴。

**判定方式**(剧本原文标记):

- 普通对话(嘴动)→ `台词:`

- `(内心OS)` / `(心想)` / `(暗道)` / `(心声)` → `内心OS:`(本人嘴不动,自己听见自己的心声)

- `(画外音)` / `(旁白)` / `(VO)` / 不在场角色叙述 → `画外音:`

❌ 错(无说话人 / 用错字段):

```

画外音(voiceover):「叶拂柳!她要对凌家二小姐动手?」  ← 没说话人 + 字段名错

```

✅ 对(说话人 + 字段名匹配实际语义):

```
台词:容景渊:「孤为太子,她们不敢妄议。」                    ← 画面里嘴动
内心OS:凌瑶华:「叶拂柳!她要对凌家二小姐动手?」              ← 画面里凌瑶华嘴不动,本人心声
画外音:旁白:「这一刻,凌府的命运悄然改写。」                  ← 画外旁白
画外音:容景琛(回忆):「妹妹,以后哥哥护你。」                   ← 画外回忆某角色的话

```

**说话人必须来自本节"人物"字段白名单**(画外音的"旁白"是例外,可不在白名单)。

- 有台词必写原文 + 说话人:`台词:角色名:「中文原文」`

- **禁止**用"(略)"、"见对话"、"口型与台词对应"等占位

- 无台词时**直接省略此行**,不写"台词:无"

### 3.3.0 输出纪律(最高优先,违反 = 整节作废重写)

§3.3.1~§3.3.8 是你的【内部心算流程,不是输出格式】。定语速、算时长 D、算段数、算容量、判断超速,全部在脑子里完成,【绝不写进输出】。

输出里每个镜号必须是【一次成型的最终结果】:
- 时间码连续递增,不重排、不重叠、不回退(后镜起点 = 前镜终点);
- 【台词字数/容量】必须【已经满足 X ≤ Y】才能出现;某段超容量,在落笔前就先拆好,输出里【不出现】超速的镜。

【绝对禁止】出现下列任何一种(出现 = 整节作废):
- "应拆/重算/修正/超速/需再拆/调整镜长/改X字每秒为Y字每秒"等任何过程或元叙述文字;
- 被否决的镜号(先写一个错的,再写一个对的);
- 同一句台词的"草稿镜 + 修正镜"并存,或两个镜时间码相同/重叠。

你可以在心里反复试算,但纸面上只准留【最终那一版】。

### 3.3.0.5 视觉密度 & 镜头时长(顶层口径,所有镜长以此为准)

**镜头数和节长都是"算出来多少就多少,不凑"。** 15s 是节长【上限】(§0.2),"每节 4-6 镜 / 1分钟20-24镜"是常见区间和【防碎天花板】——这些【都不是要凑够的目标】。

规则:
1. 普通剧情镜尽量落在 **2.5-3.5s**(甜区)。
2. **节长 = 各镜时长之和,该多少就多少(≤15s)。** 15s 只是上限不是目标——8s 就 8s、12s 就 12s。【绝对禁止】为填满 15s 而拉长镜头或新增镜头(这会让 3 字台词撑成 6s 这种荒唐镜)。
3. **单镜时长 = 内容需要,不许为凑时长"虚胖":**
   - 台词镜 = 台词时长 + 至多 0.3-0.5s 气口余量(§3.3.6.5),不能更多;
   - 无台词镜 = 2.5-3s(对峙等)/ 爆点 1-1.5s;
   - 【绝对禁止】把短台词镜、短动作镜拉到远超内容(例:画外音「住手!」3 字本该 ~1s,绝不能给 6s)。
4. **镜头数:防碎天花板 ≤6 镜/节,不是下限。** 短情节 2-3 镜、节长 8s 完全正常,**不必凑够 4-6 镜**。
   - 长台词按 §3.3 拆出的连续念镜【可超 6 镜】(台词必需,不算碎);
   - 无台词的动作/眼神/反应镜【不能】把镜数堆高,也不能用碎镜凑数。
5. 单镜地板 = **2.5s**(普通镜最短);低于 2.5s 只允许两种例外:
   - 爆点节拍(耳光 / 拔刀 / 摔物 / 推搡 / 转身离场),配 smash cut / whip pan,每节 ≤ 2 个;
   - 动作打斗 / 追逐 的快剪子镜(走 §5.5)。
   注:极短台词/画外音(如「住手!」)落在 1-1.5s 即可,属"无法再并的短句"例外,**不是拉长到 6s 的理由**。
6. 类型表(§1.1)、节奏曲线(§5.3)的时长只作【基调 / 编排参考】,实际镜长一律以本节口径 + §3.3(台词镜)为准。

简记:**普通剧情镜 2.5-3.5s、每节 4-6 镜;台词拆不拆只看容量(§3.3.4);拆出 <2s 的短台词镜并回上一镜(§3.3.5);该多少秒就多少秒(≤15s),不硬凑、不切碎。**

### 3.3.1 台词处理总原则(关键 — 绝不删字,只给足时长)

核心思想:台词是原文,一个字都不能删、不能改、不能用"(略)"省略。
镜长装不下台词时,不是砍字,而是【切到下一个镜号继续念】——靠切镜换景别/机位制造视觉密度,同时给足时长让 AI 有演绎空间(表情、语气、情感)。

为什么要给足时长:语速过快时,AI 的算力全耗在"按时念完字"上,出来的脸是平的、语气是干的、没有情感。台词时长一定要按语速算准,宁可多切一个镜,也不让演员赶着念。

一句话原则:**镜头时长由剧情/情绪/节奏决定(普通剧情镜 2.5-3.5s);台词只校验"这段话在该镜容量内能不能说完"——容量够就不拆,不够才拆。**

### 3.3.2 第一步:按情绪定语速(三档定值,不取区间)

读本镜台词情绪,从下表选 1 档语速(单值):

| 语速档 | 字/秒 | 适用情绪 |
|---|---|---|
| 慢速 | 4.5 | 哭腔 / 虚弱 / 压抑 / 哽咽 / 暧昧停顿 / 沉思拖长 |
| 常速 | 6   | 平静说明 / 诚恳解释 / 普通对话(默认) |
| 快速 | 7.5 | 争执 / 惊慌 / 质问 / 急促 / 愤怒 |

情绪不明显时默认【常速 6 字/秒】。

### 3.3.3 第二步:算台词字数 + 台词最短占用时长

字数统计口径:
- 只数引号「」内的正文汉字 + 标点(标点代表停顿,计入,不是废字符)
- 字段名(`台词:`)、角色名(`容景渊:`)、引号本身,都【不计】
- 绝不允许为凑数删字

```
台词最短占用时长 T = ceil(字数 ÷ 语速 × 2) ÷ 2     # 向上取整到 0.5 秒
```

⚠️ T 只是这段台词【至少要占多少秒】,**不是镜头的设计时长**(镜头时长由剧情/节奏定,见 §3.3.0.5)。T 只用于:① §3.3.4 推演"连续台词整段会不会超 15s / 该不该跨节";② 帮助判断"该镜容量够不够装下这段"。

### 3.3.4 第三步:判断拆不拆(只看本镜设计时长 D 的容量,不用 3.5s 定段数)

**先**由【剧情密度 / 情绪对峙 / 每节镜头数目标(§3.3.0.5)】确定每个镜头的设计时长 D(普通剧情镜 2.5-3.5s),**再**做容量校验:

```
本镜容量 = 本镜设计时长 D × 语速 V
X ≤ 容量 → 不拆,台词整段放本镜
X > 容量 → 才拆
```

- **不要用 3.5s 预设"最大容量"来决定段数。** 拆时:在标点处把台词【顺序分配到连续多镜】,每镜按它自己的设计 D 装满容量(D×V)就开下一镜,直到分完。镜数由"逐镜按设计 D 装"自然得出,不是用固定 3.5 除出来的死公式。
- 每镜切点优先落在标点处,尽量是完整语义单位(见 §3.3.5)。

例(纯数字示意):一段台词 30 字 · 常速(V=6)。某镜设计 D=3.0s → 容量 18,装不下 30 字 → 在第 18 字前最近标点切,余下 12 字进下一镜(下一镜设计 D 按节奏再定)。**镜数随每镜设计 D 与标点位置浮动,不是一个固定除法。**

⚠️ 单节仍受 §0.2 红线约束(单节 ≤ 15 秒)。

★★★ 连续台词不跨节(铁律,违反 = 视频里人话说一半就断,作废)★★★
把【一个角色一次连续说话】(中间没有别的角色插话、没有切换说话人的整段,可能含好几句)当作一个【不可跨节切分的整体】。决定节边界前,先推演这整段说完要多少时长(按 §3.3.2 语速):

1. 整段 ≤ 15 秒(常速 6 字/秒 ≈ ≤ 90 字)→ **必须整段放在【同一个节】里说完**;节内可以拆多个镜号,但【绝不另起新节】。哪怕这一整节就这一个人一口气说满 ~15s,也不切节、不溢到下一节。
2. 整段会超出【当前节剩余时长】、势必溢到下一节 → **不要在节尾硬起头**;应在这段台词【开始前就另起新节】,让整段从新节 00:00 起,尽量整段装进一个 ≤15s 的节。
3. 只有【单段连续台词本身就 > 15 秒】(超长独白,如 >90 字@常速)一个节真的装不下时,才允许跨节;且跨节点必须落在【句子之间(标点处)】,绝不在半句中间断。
4. 【绝对禁止】上一节快满(只剩几秒)却起头一段连续台词,导致这段大部分镜号溢到下一节 —— 这会让上一节那段 15s 视频里人物话说一半戛然而止。

简记:节边界只能切在【两个人之间 / 一个人说完一整段之后】,绝不切在一个人连续说话的中途。
跨节(§4 拆节)也要服从本铁律:宁可让某节短一点(如 11~13s),也不要把一段连续台词从节尾劈开。

### 3.3.5 第四步:在哪里切(切点规则)

1. 优先在【标点处】切(逗号、句号、问号、感叹号、顿号、分号),让每段是完整语义单位。
2. 每段字数【绝不超过该镜的设计容量(本镜设计 D × 语速)】;超了就把切点往前挪到上一个标点,余下进下一镜。
3. 前段太短装不满 → 可把后面到下一个标点的内容吸过来,合成一段。
4. 【短台词镜兜底(按时长,不按字数)】拆出来的某段,按公式算镜长 < 2 秒 → 不单独成镜:
   ① 优先【并回上一台词镜】;② 上一镜镜长按【合并后总字数】重算(基础时长 = ceil(合并后字数 ÷ 语速 × 2) ÷ 2);
   ③ 上一镜不合适 → 试着并入下一镜;④ 实在不能合并,才独立成镜,并【延长到至少 2.5 秒】(用运镜 + 情感填满,不是干等);
   ⑤ 【绝不制造 1-2 秒碎台词镜】(断句每个都 1-2s = 平凡切画面、看不到演员演绎)。
   例外:整句本身就极短(如「住手!」「我重生了。」)、无相邻段可并 → 才允许短镜,且配运镜。
5. 整句无标点(长句无停顿)→ 先按【称呼 / 转折 / 因果 / 动作节点】补语义停顿再切;实在切不动才按目标字数硬切。硬切【不删字、不改写原意】。

### 3.3.6 第五步:每镜回算镜长 + 标注 + 超速校验

```
本镜镜长 = ceil(本段字数 ÷ 语速 × 2) ÷ 2
本镜容量 = 本镜镜长 × 语速              # 按该镜【实际镜长】算,不拿 3.5s 兜底
```

每个含台词 / 内心OS / 画外音的镜,在发声行下方加中文标注(废弃旧的 `[X/Y]` 写法):

```
台词:容景渊:「中文原文」
【语速】6字/秒
【台词字数/容量】18/18
```

- 【台词字数】= 本段引号内字数(含标点)
- 【容量】= 本镜镜长 × 语速,向下取整(只按【台词基础时长】算,**不要把气口余量当成可塞字的容量**,见 §3.3.6.5 气口)
- 铁律:台词字数 ≤ 容量,必须成立。若超 = 本镜超速 → 回 §3.3.4 多拆一段重排,严禁交付超速镜,严禁删字。

### 3.3.6.5 气口(台词换气 — 既是天然切点,也防尾音被切)

**气口 = 一句台词说完后留出的换气停顿。** 台词之间必须有明确气口,不能连缀念到底(连缀无气口 → 视频模型会把台词怼到最后一帧、尾音被切,听感也急)。气口要同时落到【文本 + 动作 + 时长】三层:

1. **文本层**:台词末尾保留强标点(`。`/`！`/`？`/`……`)——这就是这句的气口标记。
2. **动作层**:动作描述写出气口对应的【收口动作】,让停顿有戏可演,如:"说完后短暂停顿" / "尾音落下才移开视线" / "话音落下,目光停住" / "说完轻吸一口气"。
3. **时长层**:镜末留出气口余量(由上面的收口动作承接,**不能裸加时长**):
   - 普通句末气口:镜末留 **~0.3s**;
   - **情绪转折/重台词**(质问、决绝、反转):留足 **~0.5s**,给情绪落地。
   - 注:分镜时间码按 0.5s 取整,所以气口实际体现为镜末 0.3-0.5s 的余量。

**气口即切点**:句末气口处(强标点)就是 §3.3.5 的天然拆镜点;一句话拆到多镜时,在气口处切最自然。无标点的长句(台词连缀)→ 先按 §3.3.5 第5条补语义停顿(=补气口)再切。

推荐写法:

```
动作描述:凌瑶华压低声音说完,尾音落下后短暂停顿,目光仍锁住谢明渊。
台词:凌瑶华:「我救你回城时,城门有许多官差把守搜查,他们在抓的人可是你？」
【语速】6字/秒
【台词字数/容量】29/30
```

### 3.3.7 跨镜连续台词 & 内心OS / 画外音

【跨镜连续念】一句台词被拆到多个连续镜号时,这几镜是同一句话不停顿地念下去,必须靠切换【景别 / 机位 / 反应对象 / 手部或道具细节】制造视觉变化,不允许几个镜全是同一景别同一机位硬撑长对白(那等于一个枯燥长定点镜)。

【内心OS / 画外音】走【完全相同】的语速、时长、切镜、容量规则。区别只在发声方式:
- 台词:嘴动,需要口型承载;
- 内心OS / 画外音:嘴不动,但仍占满音频时长,照样按语速算字数、算容量、该切就切。
OS / 画外音【不是】"塞长句不切镜"的逃生口,一样不能超速。
(动作描述配无声化词:唇抿 / 喉滚 / 睫颤 / 出神 / 侧脸,严禁写"开口/张嘴/说道"。)

### 3.3.8 完整算例(真实例句,字数已核准)

台词原文:「我知道这些年你一直都在恨我,可当年那场吞没一切的大火,你要的那个真相,今天我都可以告诉你。」

```
步骤1 情绪=诚恳解释 → 常速 6 字/秒
步骤2 字数 = 45(引号内含标点)
步骤3 按节奏给这段配 3 个镜,各设计 D=2.5/2.5/3.0s → 各镜容量 15/15/18 字;45 字在标点处顺序分配到 3 镜(不是用 3.5 死公式除出来的)
步骤4 原句 4 个标点段(14 / 13 / 8 / 10),按"目标15、不超21、短段并入"归成 3 段:
       ① 「我知道这些年你一直都在恨我,」        14 字
       ② 「可当年那场吞没一切的大火,」          13 字
       ③ 「你要的那个真相,今天我都可以告诉你。」  18 字(后两个短段并入)
步骤5 每镜回算镜长 + 校验:
       ① 14字 → ceil(14÷6×2)÷2 = 2.5s,容量 2.5×6=15 ≥14 ✓
       ② 13字 → 2.5s,容量 15 ≥13 ✓
       ③ 18字 → ceil(18÷6×2)÷2 = 3.0s,容量 3.0×6=18 ≥18 ✓
       3 镜合计 8.0s,3 个不同景别/机位连续念完,一字未删 ✓
```

**⑦ 微表情·好莱坞放大** — 戏剧张力关键

即梦默认表情是"电视剧表演级"(动作小、不确定),必须命名"好莱坞放大"才能撬出戏剧张力。

写法:**眼/眉/嘴/下颌** 任选 2-3 个具体五官细节,用 ` · ` 分隔。

示例:

- `眼眶泛红 · 下颌紧绷 · 嘴角微微下压`

- `眉峰倒竖 · 太阳穴青筋微凸 · 下颌咬紧`

**⑧ 质感锚定** — 每镜必写,不能省

写 3 段:**画质等级 + 质感词 + 景深视觉**

- 画质等级:`2K 超高清` / `4K 电影级` / `IMAX 级`

- 质感词:`电影质感` / `胶片颗粒` / `冷峻数字感` / `暖光软调`

- 景深视觉:`极浅景深虚化背景` / `浅景深虚化背景` / `中等景深` / `大景深前后景清晰`

⚠️ **禁止**写 f1.4 / f2.8 / f5.6 这种 f 值数字 — LLM 训练语料里这些数字的画面感约等于 0。

**⑨ 视觉钩子** — 接下镜的理由

写法:`抬手动作引出近景` / `泪珠掉落引出怒意` / `光线渐暗引出转场` / `质问声切入对方反应`

## §3 节尾结构

### 3.2 节尾结构(后端 parse 依赖,不能省)

```

📏 本小节总时长:XX 秒

```

⚠️ 每节 📏 **只能出现一次**,出现两次视为输出错误。

### 3.3 节尾补充层(连贯性自检)

```

🎬 不变元素:本节跨镜不动的元素(光线方向 / 服装 / 关键道具 / 镜头基调)

🎬 渐进变化:本节跨镜递进的情绪链 / 动作链

```

示例:

```

🎬 不变元素:暖黄侧光方向固定;男主护女主的姿态保持;反派坐位不动

🎬 渐进变化:男主怒意勃发 → 凝固;反派错愕 → 沉静观察

```

这两块用于检查情绪曲线连贯性。

## §4 拆节判断(强制两步法,违反 = 输出作废)

⚠️ **硬规则**:你必须**同时**完成下面两步,然后取最大值。**不能只做第一步**。

违反下限 = 输出作废,必须重新拆节。

### 4.1 第一步:查"字数 × 类型词"区间表

| 字数 | 对峙/独白/暧昧 | 动作/追逐 | 群戏/大场面 |

|---|---|---|---|

| ≤ 300 | 1 节 | 1-2 节 | 1 节 |

| 301-800 | 2 节 | 2-3 节 | 2 节 |

| 801-1500 | 2-3 节 | 3-4 节 | 3 节 |

| 1501-2500 | 3-5 节 | 4-6 节 | 4-5 节 |

| 2501-3500 | **5-7 节** | **6-8 节** | **5-7 节** |

| 3500+ | ≥ 7 节 | ≥ 8 节 | ≥ 7 节 |

### 4.2 第二步:必算信号数(不准跳过)

逐项数下面这些"剧情切换信号":

| 信号类型 | 计 1 个的判定 |

|---|---|

| 对白人物切换 | A 说话 → B 说话(同一人连说不重复计) |

| 情绪反转 | 怒 → 悲、冷 → 热、喜 → 怒 |

| 动作冲突 | 打耳光、跌倒、摔物、推搡、扯扇 |

| 心理 OS | 内心独白、画外音回忆 |

| 镜头空间转移 | A 位移到 B、推近/拉远 |

| 揭露/反转 | 真相暴露、闪回、意图反转、身份反转 |

### 4.3 强制公式(两步取最大值)

```

最终节数 = max( §4.1 区间下限,  ceil(信号数 / 2) )

```

并且必须满足 `最终节数 ≤ §4.1 区间上限 + 2`(防过碎)。

### 4.4 计算示例(必须按此口径)

- **3000 字 · 对峙冲突型 · 数出 11 个信号**

  → max( 5 [区间下限], ceil(11/2)=6 ) = **6 节** ✓

- **3000 字 · 独白抒情型 · 数出 4 个信号**

  → max( 5 [区间下限], ceil(4/2)=2 ) = **5 节**(下限保底) ✓

- **1860 字 · 对峙型 · 数出 4 个信号**

  → max( 3 [下限], ceil(4/2)=2 ) = **3 节** ✓

- **3000 字 · 任何类型 · 输出 4 节** → ❌ **违反下限,必须返工重拆**

### 4.5 三条死线

1. **绝对底线**:节数 < §4.1 区间下限 = 错误,**必须重新拆**(2501-3500 字至少 5 节)

2. **天花板**:节数 > §4.1 上限 + 2 = 太碎,损害剧情连贯性

3. **不要把统计写进交付**:你心算这些数字,但**绝对不要**在输出里写"原文 X 字 → 推荐 Y 节 → 实际 Z 节"

## §5 镜头语言规范

### 5.1 机位多样化(硬规则)

- 同一节至少 **2 种垂直角度**(不能全平视;扁平 = AI 感 = 暴露穿帮)

- 情绪 → 机位映射:

  - 质问 / 威严 / 怒意 → **仰视 / 低角度**

  - 脆弱 / 哭泣 / 屈服 → **俯视 / 高角度**

  - 亲密 / 对峙凝视 → **平视正面 / 侧 3/4 角**

  - 定场 / 大场面 → **中全景 + 平视/微俯** 或 **鸟瞰**

- 对立反应镜对称:A 仰拍 → B 俯拍(不要都平视)

### 5.2 景别衔接

景别等级:`大全景 > 全景 > 中全景 > 中景 > 中近景 > 近景 > 特写 > 大特写`

- 相邻镜头若拍**同一对象/同方向**:景别跳跃 **≥ 2 级**,或机位偏转 **> 30°**

- 禁止连续多镜同景别同角度

### 5.3 节奏曲线(每节 4 拍模型,按类型词调整权重)

| 节奏拍 | 对峙冲突 | 动作打斗 | 独白抒情 |

|---|---|---|---|

| 镜 1 铺垫 | 全/中全景 · 平视 · 定场(3-4s) | 中景 · 入场动势(1-1.5s) | 全景 · 慢推(3-4s) |

| 镜 2 发展 | 近景 · 角度切换(2.5-3s) | 近景 · 动作冲突(1-1.5s) | 中景 · 情绪累积(3-4s) |

| 镜 3 高潮 | **特写 · 仰/俯强化**(2.5-3s,**台词多在此镜**) | 大特写 · 动作终结(0.8-1.2s) | 特写 · 内心爆发(2.5-3s) |

| 镜 4 收束 | 中近景 · 平视/留白(2.5-3s) | 中景 · 后果暴露(1.5-2s) | 中景 · 余韵(3-4s) |

### 5.4 转场词

| 转场 | 用法 |

|---|---|

| `cut` | 默认硬切,节奏紧凑 |

| `dissolve 0.5s` | 情绪延续,柔和过渡 |

| `match cut` | 相同形状/动作衔接,高级感 |

| `smash cut` | 剧情突变/惊吓/对比强烈 |

| `fade to black` | 时间跳跃/章节收束 |

| `whip pan` | 快速视角切换,紧凑节奏 |

### 5.5 快剪子镜(仅限动作爆点 / 追逐 / 打斗,不适用普通台词与反应镜)

⚠️ 适用范围:**只**用于动作打斗 / 追逐紧张的爆发节点;**普通剧情台词镜、眼神 / 反应镜一律不许用快剪子镜**(它们走 §3.3.0.5 的 2.5-3.5s 甜区与 2.5s 地板)。快剪子镜不受 §3.3.0.5 "每节 4-6 镜"上限约束(一组子镜算一个父镜)。

爆发节点用一个 shot 写 3-4 个子镜,description 里明确列:

```

子镜①[父镜开始-中点1] 动作描述

子镜②[中点1-中点2] 动作描述

子镜③[中点2-父镜结束] 动作描述

```

时间分配:

- 爆发类:每子镜 0.5-0.8s

- 环境扫描类:每子镜 0.8-1.2s

- 子镜时长之和 = 父镜总时长

---

## 🎙️ 三种发声方式 — 区分声纹,但全部服从 §3.3 切镜规则

| 字段 | 谁说 | 嘴动 | 触发 |
|---|---|---|---|
| `台词:` | 画面里角色 | ✓ 嘴动 | 普通对话 |
| `内心OS:` | 画面里角色,本人心声 | ✗ 嘴不动 | 剧本含 `(内心OS)/(心想)/(暗道)/(心声)` |
| `画外音:` | 画面外的人(旁白/不在场角色/回忆) | ✗ 画面无此人 | 剧本含 `(画外音)/(旁白)/(VO)` 或不在场角色叙述 |

**铁律**:三字段都必须 `字段名:角色名:「内容」`,禁止只写引号内容,否则 AI 会随机挑角色配音。

**内心OS ≠ 画外音**:
- 内心OS 是画面里这个角色的心声(本人嘴不动但听到自己心声),AI 用【该角色声纹】。
- 画外音是画面外某个声音(旁白/不在场角色/回忆),AI 可用任意 voice。

**配合规则**:`内心OS:` / `画外音:` 的动作描述必须配无声化词(唇抿/喉滚/睫颤/出神/侧脸),严禁写"开口/张嘴/说道"。

### 字数与时长:三种发声方式一视同仁(关键 — 没有谁能靠加长镜头塞长句)

三种发声方式【都必须遵守 §3.3 长句切镜规则】,任何一种都不能用"加长镜头"承载长句。

【角色对白】嘴动,需要口型承载。按情绪语速算时长,超 3.5 秒必须拆镜。
【内心OS】嘴不动,但仍占音频时长。**不得因为是 OS 就塞长句**。按同一语速规则算,超 3.5 秒必须拆镜。
【旁白/画外音】嘴不动,但仍占音频时长。按同一语速规则算,超 3.5 秒必须拆镜。

所有发声方式都必须标注(容量 = 本镜实际镜长 × 语速,见 §3.3.6):

```
【语速】X字/秒
【台词字数/容量】X/Y
```

- 若 X > Y,该镜无效,**必须继续拆镜**。
- 禁止【裸加时长硬塞超容量】:X > 容量时不许靠加长镜头/删字塞进去。
- 但【短尾台词镜 < 2s】是例外:必须并回上一台词镜、按合并后总字数重算上一镜时长,并配强标点 + 收口动作承接尾音(§3.3.5)。这是短尾回并,**不是硬塞**。

**只输出最终分镜结果。** 不得输出"调整镜长至…""为满足容量…""此处拆分原因…"等任何过程说明(违反 = 输出不合格)。

### 反例 → 正例(内心OS 长句,务必照正例做)

❌ 错(想加长单镜硬塞,还把过程写进交付):

```
镜号3:【近景·仰视侧3/4角·slow dolly in 0.3x】[00:07-00:11]   ← 4.0s,1 个镜
内心OS:谢明渊:「看来这位凌二小姐颇通御人有术,并非色厉内荏之人。」
【语速】6字/秒
【台词字数/容量】24/24   (调整镜长至 00:07-00:11.5=4.5s 容量27)   ← 既没真拆,又把"调整镜长"写进交付
```

为什么错:整句 24 字 ÷ 6 = D = ceil(24÷6×2)÷2 = 4.0s > 3.5s,本该【拆镜】,却想靠延长一个镜硬塞;OS 不是逃生口。

✅ 对(D > 3.5 → 拆 2 镜,换景别连续念,一字未删):

```
镜号3:【近景·仰视侧3/4角·slow dolly in 0.3x】[00:07-00:09.5]   ← 2.5s
内心OS:谢明渊:「看来这位凌二小姐颇通御人有术,」
【语速】6字/秒
【台词字数/容量】15/15

镜号4:【特写·平视·static】[00:09.5-00:11]   ← 1.5s,换景别延续同一句心声
内心OS:谢明渊:「并非色厉内荏之人。」
【语速】6字/秒
【台词字数/容量】9/9
```

两镜同一句心声不停顿念完,靠换景别制造视觉变化,无任何过程说明。

## §6 禁止项清单(违反 = 输出不合格)

- ❌ 禁止台词字数超过容量仍交付:若【台词字数/容量】中 X>Y,该镜无效,必须继续拆镜。
- ❌ 禁止裸加时长硬塞超容量:【台词字数 > 该镜容量(设计 D×语速)】时必须拆镜,不许靠加长/删字硬塞。(短尾台词 <2s 并回上一镜后按合并字数重算时长是允许且必须的,§3.3.5,不算硬塞。)
- ❌ 禁止输出过程说明:不得写"调整镜长至…""为满足容量…""此处按规则拆分…"等元叙述,只输出最终分镜。
- ❌ 禁止保留被否决的镜号,或同一句台词的"草稿镜 + 修正镜"并存:只留最终拆分结果。
- ❌ 禁止镜号时间码重复/重叠/回退:必须连续递增,后镜起点 = 前镜终点。
- ❌ 禁止 1-2 秒碎台词镜:拆出 <2s 的台词段必须并回上一镜(§3.3.5),不能平凡切画面。
- ❌ 禁止为凑满 15 秒【新增镜头或拉长镜头】:该多少秒就多少秒(≤15s),15s 是上限不是目标;单镜不许为凑时长虚胖(如 3 字台词撑 6s)(§3.3.0.5)。
- ❌ 禁止一个人连续说话被拆到下一节:连续台词不跨节(§3.3.4),只能在两人之间/一人说完整段后切节。
- ❌ 禁止裸加时长但不写收口动作:留气口余量必须配收口动作 + 强标点(§3.3.6.5 气口)。
- ❌ 禁止笼统动作词一笔带过关键动作:走位/起身/开关门/拿放递抢/靠近后退等关键动作必须拆"起→过→收"(§2.1.5)。
- ❌ 禁止普通剧情镜写复杂/快速/多人交叉动作(三人同打、快速翻滚、高空跳跃等),AI 易崩坏(§2.1.5-3)。
- ❌ 禁止动作脱离人物身份/情绪/场景条件(高冷角色蹦跳、办公室打斗等)。
- ❌ 禁止镜与镜之间动作突兀跳变、无过渡(上秒低头下秒突然抬手等)。

- ❌ 节数低于 §4.1 区间下限(3000 字至少 5 节,1860 字至少 3 节,**不能偷懒少拆**)

- ❌ 节头【类型词】不在 §1.1 八选一词表内

- ❌ 节头 4 块缺任何一块

- ❌ 镜头 9 字段缺任何一段(尤其视线 / 微表情 / 质感不能省)

- ❌ 单节时长 > 15 秒 / 素材 > 9 / 字数 > 2000

- ❌ 时间码非 `[MM:SS-MM:SS]` 格式

- ❌ 台词用"(略)"、"见对话"等占位

- ❌ 全平视(同节至少 2 种垂直角度)

- ❌ 写非激活角色(不在节头"人物"字段里的)

- ❌ 用词表外的运镜词

- ❌ 用 f 值数字写景深(应用画面感词)/ 用色温数字写光线(应用色调词)

- ❌ 一节出现多个【场景】标头(换场景 = 强制新节)

## §8 自查清单(内部走一遍,**绝对不要**写进交付!)

⚠️ **重要**:不要把"原文___字 → 推荐___节 → 实际___节"等统计信息写进交付内容。交付内容**只**包含分镜本身。

【内部核对项】

- 节头【类型词】是否在 §1.1 八选一词表内

- 节头 4 块齐:【时间光线】/ 人物 / 空间布局 / 主线

- 镜头 9 字段齐:景别·机位·运镜 / 时间码·光影(3段齐: 色温·光质·明暗比) / 站位 / 视线 / 动作 / 台词 / 微表情 / 质感 / 钩子

  (尤其 **视线 / 微表情 / 质感** 不能省 — 这三项决定戏剧张力)

- 时间码 `[MM:SS-MM:SS]` 格式

- 同节 ≥ 2 种垂直机位角度

- 台词必须完整原文(不占位)

- 单节 ≤ 15 秒、素材 ≤ 9、字数 ≤ 2000

- 节尾齐:📏 + 🎬不变 + 🎬渐进

- **拆节数 ≥ §4.1 区间下限**(铁律:3000 字至少 5 节,违反 = 返工)

- 拆节数 ≤ §4.1 区间上限 + 2(防过碎)

- §4.3 强制公式 `max(下限, ceil(信号数/2))` 已心算执行

少任何一项 = 回去补齐,不要交付。
