# 万山漫剧使用链路与音频教程

本文面向测试用户和后续接手开发的 AI，说明万山漫剧从小说到视频的完整链路，以及“音频/音色”到底如何导入、如何参与视频生成。

## 1. 软件能做什么

万山漫剧是一套“小说/剧本 → 角色场景道具资产 → 分镜 → AI 视频”的漫剧制作工作台。核心目标是把长篇小说快速拆成可批量生产的视频素材：

1. 小说导入：导入 txt 小说，按章节管理。
2. 剧本转换：选择章节和剧本模板，一键把小说改成短剧剧本。
3. 信息提取：从剧本里提取人物、场景、道具。
4. 资产生成：批量生成人物宫格图、场景图、道具图，也支持导入已有成品图。
5. 音频绑定：给人物或人物马甲导入短音频，作为视频生成时的角色音色参考。
6. 分镜管理：把剧本按分镜模板生成小节分镜。
7. 即梦视频生成：把分镜、人物图、场景图、道具图、音频参考一起提交给视频模型，批量出视频。

## 2. 推荐使用流程

### 第一步：配置模型

进入“设置 → 大模型配置”，建议至少配置三类模型：

- 语言大模型：用于小说转剧本、信息提取、打标签、分镜生成。
- 图片大模型：用于生成人物、场景、道具、封面、宫格图。
- 视频大模型：用于最终视频生成。

“语音大模型”目前主要是配置预留项。当前稳定生产链路不是文字自动 TTS 配音，而是先导入人物音频样本，再把音频作为视频生成的参考素材传给支持音频的视频通道。

### 第二步：导入小说

进入“小说导入”：

1. 导入 txt 小说。
2. 检查章节是否拆分正确。
3. 使用“小说标签”或“AI 智能分析打标签”补齐屏幕模式、视觉标签、题材标签。

注意：未打标签的小说可能无法进入某些分镜/视频流程，因为系统需要知道竖屏/横屏、真人/动漫/3D 等视觉方向。

### 第三步：小说一键转剧本

进入“剧本转换”：

1. 选择小说。
2. 勾选章节。
3. 选择剧本提示词模板。
4. 选择语言大模型配置。
5. 点击转换。
6. 在右侧检查生成的剧本，确认后保存。

这一环节的目标是把小说变成后续能拆分镜、提取资产的剧本格式。

### 第四步：提取人物、场景、道具

进入“信息提取”：

1. 选择小说。
2. 选择已生成的剧本。
3. 点击“提取人物”“提取场景”“提取道具”。
4. 如果提示没有剧本，需要先回到“剧本转换”生成并保存剧本。

提取后会生成三类资产卡片：

- 人物：角色名、外貌描述、人物图、马甲、音频。
- 场景：地点、氛围、光影、场景图。
- 道具：关键物件、外观、用途、道具图。

### 第五步：生成人物、场景、道具资产

在“信息提取”里可以直接做资产：

- 人物卡片：生成宫格图，确保正面、背面、侧面、表情、服装等一致。
- 场景卡片：生成可作为视频背景参考的场景图。
- 道具卡片：生成关键道具图。
- 上传参考图：给模型一个参考，不一定是最终图。
- 导入成品图：直接把已有图片作为正式资产。
- 迁移资产：把别的小说中已经做好的角色/场景/道具迁移到当前小说。

建议先把主要人物和主场景做好，再去批量跑分镜视频。否则视频模型会凭空发挥，角色一致性会变差。

## 3. 音频是怎么导入的

当前音频入口在“信息提取 → 人物卡片”里。

### 给人物本体导入音频

1. 进入“信息提取”。
2. 切到“人物”标签。
3. 找到对应角色卡片。
4. 点击“导入音频”或麦克风按钮。
5. 选择本地音频文件。
6. 保存成功后，该人物就有了音色参考。

支持格式：

- mp3
- wav
- m4a
- ogg
- flac

限制：

- 文件最大 50MB。
- 即梦/Seedance 链路建议 2 到 15 秒。
- 最好是干净人声，不要背景音乐，不要多人混说，不要长段台词。

### 给人物马甲导入音频

如果一个角色有多个形象或身份，例如“本体”“黑袍”“少年版”“女装”等，可以用马甲区分。

1. 在人物卡片里打开“马甲/管理”。
2. 新建或选择一个马甲。
3. 给这个马甲导入图片和音频。
4. 视频生成时，如果分镜命中该马甲，就可以使用对应音频。

这样可以做到同一个角色不同状态下使用不同参考图和不同音色。

## 4. 音频是怎么生成的

当前版本要分清楚两件事：

- 已实现：导入已有音频，把它绑定到人物或马甲，作为视频生成时的音色参考。
- 未完整实现：根据剧本文字自动调用语音模型生成每句台词音频。

也就是说，现在的正式链路是：

```text
外部录音/外部 TTS 生成短音频
→ 在万山人物卡片里导入音频
→ 分镜视频生成时自动带上角色音频参考
→ 支持音频的视频模型根据参考音色生成带声音的视频
```

如果用户想要人物说话声更像某个角色，应该先准备这个角色 2 到 15 秒的干净音频样本，再导入角色卡片。

后续可以继续开发“文本自动生成音频”功能，让软件根据剧本台词直接调用语音大模型生成音频文件，再自动绑定到分镜或角色。

## 5. 音频如何进入视频生成

视频生成时，系统会读取当前分镜关联到的人物、场景、道具资产：

1. 人物图会作为人物参考图。
2. 场景图会作为环境参考图。
3. 道具图会作为物件参考图。
4. 人物音频会作为角色音色参考。

在支持音频的视频通道里，系统会把音频作为 `reference_audio` 或同类参数提交。当前逻辑最多优先携带 3 段音频，避免请求过大或平台限制。

如果开启“按说话人自动过滤音频”，系统会尽量只给当前分镜里真正说话的人物带音频。不说话的人物音频会自动屏蔽，避免视频里乱串声音。

## 6. 分镜到视频的完整链路

### 分镜管理

进入“分镜管理”：

1. 选择小说。
2. 选择章节。
3. 选择分镜模板。
4. 选择语言大模型。
5. 选择风格提示词。
6. 点击“批量生成全部分镜”。

生成后，右侧会出现每个小节的分镜内容。分镜里会包含场景、人物、状态、镜号、秒数、成片提示词等。

### 即梦视频生成

进入“即梦视频生成”：

1. 选择视频生成通道。
2. 选择模型、参考模式、比例、分辨率、时长、风格提示词。
3. 选择小说和章节。
4. 勾选要生成的视频小节。
5. 点击批量生成。

视频生成通道说明：

- 即梦 CLI：走本地 Dreamina CLI，需要即梦账号已登录，并且账号具备 CLI/高级会员权限。
- 火山方舟 API：走火山视频模型接入点，适合商业化批量调用。
- 中转/Cool/星链云：走第三方或中转服务，是否支持音频取决于对应模型能力。

## 7. 常见问题

### 为什么我导入了音频，但视频里没有声音？

常见原因：

1. 当前视频通道或模型不支持音频参考。
2. 当前分镜里该角色没有台词，且开启了“按说话人自动过滤音频”。
3. 音频太长、太短、格式不被平台接受。
4. 一次携带音频太多，系统只保留前 3 段。
5. 视频模型本身没有开启生成声音的能力。

### 为什么即梦 CLI 显示登录失败？

网页登录成功不等于 CLI 权限可用。即梦 CLI 需要本地 CLI 工具、账号登录状态，以及对应账号具备高级会员或 CLI 调用权限。若日志提示需要开通高级会员，需要在即梦官方账号侧处理。

### 为什么点“提取人物/场景/道具”马上返回 0 个？

优先检查是否已经生成并保存剧本。信息提取不是直接从小说原文里随便抽，它更适合从已转换好的剧本中提取资产。如果没有剧本，应该先去“剧本转换”。

### 为什么图片模型下拉显示 No Data？

通常是模型配置类型没选对。生图功能只读取“图片大模型”配置；分镜和剧本功能读取“语言大模型”；视频生成读取“视频大模型”。

### 为什么需要人物宫格图？

人物宫格图用于固定角色外观，包括正面、背面、侧面、表情、服装、材质等。它能显著提高连续视频里的人物一致性。

## 8. 给测试用户的 5 分钟教程

1. 先到设置里填好语言、图片、视频模型 Key。
2. 导入小说，确认章节拆分没问题。
3. 给小说打标签，补齐屏幕模式和视觉标签。
4. 到剧本转换里选择章节，一键转剧本并保存。
5. 到信息提取里提取人物、场景、道具。
6. 给主要人物生成人物宫格图，给主要场景生成场景图。
7. 如果要角色声音，给人物导入 2 到 15 秒干净音频。
8. 到分镜管理里批量生成分镜。
9. 到即梦视频生成里选择视频模型和章节，批量生成视频。
10. 如果视频效果不稳定，先补人物图、场景图、道具图，再重新生成分镜或视频。

## 9. 当前待增强功能

下面是后续可以继续开发的能力：

1. 文本自动 TTS：根据剧本台词调用语音模型生成每句音频。
2. 台词级音频绑定：不仅给角色绑定音色，还能给每句对白绑定具体音频。
3. 音频批量生成：按章节一键生成全部角色台词音频。
4. 音频预览与裁剪：导入后直接在软件里试听、裁剪到 2 到 15 秒。
5. 视频生成前资产检查：自动提示缺人物图、缺场景图、缺音频、模型不支持音频等问题。
